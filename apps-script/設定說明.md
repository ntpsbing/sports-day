# 手機通知設定說明（瀏覽器關掉也收得到）

網站發出「通知老師」後，這支 Apps Script 每分鐘檢查一次，用兩條路送到老師手機：

| | ① Email（學校 Gmail） | ② 手機推播 |
|---|---|---|
| 哪些手機 | **全部**（Android、iPhone 都可以，iOS 版本不限） | Android；iPhone 要加入主畫面、iOS 16.4 以上 |
| 老師要做什麼 | 手機裝 Gmail App、登入學校帳號（大多數老師已經有） | 網站 🔔 開啟通知 |
| 你要設定什麼 | **只有第 3 步** | 第 1～3 步 |
| 多快 | 約 1 分鐘內 | 約 1 分鐘內 |

**最快上手：先只做第 3 步，Email 通知就能用了。** 有空再做第 1、2 步加上手機推播。

請用 Firebase 專案擁有者的學校帳號操作（目前是系統管理員帳號）。

---

## 第 1 步（推播用，可以晚點做）：產生「網路推播金鑰」（3 分鐘）
1. 打開 https://console.firebase.google.com ，選專案 **nanzi-sportsday**。
2. 左上角齒輪 →「專案設定」→ 上方分頁「**Cloud Messaging**」。
3. 往下找「網路設定」→「網路推播憑證」→ 按「**產生金鑰組**」。
4. 複製出現的那一長串（以 B 開頭，約 88 個字）。
5. 打開 `config.js`，貼在 `window.FCM_VAPID_KEY = "";` 的引號中間，存檔上傳。
   （也可以直接把這串貼給 Claude，請它幫你更新。這是**公開金鑰**，貼出來是安全的。）

## 第 2 步（推播用，可以晚點做）：更新資料庫規則（2 分鐘）
新增了「推播裝置」這一類資料，規則要更新一次。
1. Firebase 主控台左側「**Firestore Database**」→ 上方「**規則**」。
2. 把整個 `firestore.rules` 檔案的內容貼上，取代原本的內容。
3. 按「**發布**」。

## 第 3 步：建立 Apps Script 程式（8 分鐘）← Email 通知只要做這步
1. 用同一個學校帳號打開 https://script.new （會建立新的 Apps Script 專案）。
2. 左上角把專案名稱改成「運動會推播」。
3. 把編輯器裡的程式全部刪掉，貼上 `apps-script/推播.gs` 的全部內容，按 💾 存檔。
4. 左側齒輪「**專案設定**」→ 勾選「**在編輯器中顯示「appsscript.json」資訊清單檔案**」。
5. 回到左側「編輯器」→ 點 `appsscript.json` → 全部刪掉，貼上 `apps-script/appsscript.json` 的內容 → 存檔。
6. 上方函式選單選「**設定**」→ 按「**執行**」。
   - 第一次會跳出授權視窗：選你的學校帳號 →（若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往 運動會推播」）→「允許」。
   - 下方執行記錄出現「✔ 已設定每分鐘自動檢查」就完成了。

## 第 4 步：測試（2 分鐘）
**Email**：Apps Script 函式選單選「**測試推播**」→「執行」。你的學校信箱會收到測試信，手機 Gmail App 會跳通知。

**手機推播**（做完第 1、2 步才有）：
1. 用手機打開網站並登入 → 右上角 🔔 →「開啟手機／桌面通知」→ 允許。
   - 🔔 裡會顯示「📲 瀏覽器關掉也收得到（推播）：✔ 這台已登記」。
   - iPhone 要先用 Safari「分享 → 加入主畫面」，從主畫面圖示打開再開通知（iOS 16.4 以上）。
2. **把手機瀏覽器整個關掉、手機鎖屏。**
3. 回到 Apps Script，函式選單選「**測試推播**」→「執行」。手機應該幾秒內跳出「運動會通知（測試）」。
4. 再測正式流程：電腦在網站 🔔 按「📲 傳到我所有裝置」，約 1 分鐘內手機會跳出。

## 給老師的說明（可以直接轉貼到教師群組）
> 運動會當天，大會的集合、頒獎通知會寄到您的**學校 Gmail**。請在手機上：
> 1. 安裝 **Gmail** App，登入學校帳號（xxx@e1.ntps.kh.edu.tw）。
> 2. 手機「設定 → 通知 → Gmail」確認允許通知；Gmail App 裡「設定 → 學校帳號 → 通知」選「所有郵件」。
> 3. 收到【運動會通知】就是大會的即時訊息。
>
> 想要更即時：打開運動會網站、登入、按右上角 🔔「開啟手機／桌面通知」。

## 運動會結束後
Apps Script 選「**停用**」→「執行」，就會停止每分鐘檢查。明年要用再執行一次「設定」。

## 疑難排解
| 狀況 | 怎麼辦 |
|---|---|
| 老師說沒收到 Email | 請老師查看 Gmail 的「促銷內容／社交網路」分頁或垃圾郵件，把信標成「重要」；手機 Gmail 通知要選「所有郵件」 |
| Email 只寄給部分老師 | 收件人是「帳號與權限」設定過的人＋登入過網站的人；請老師先登入網站一次 |
| 🔔 顯示「管理員尚未設定推播金鑰」 | 第 1 步的金鑰還沒貼到 `config.js`，或還沒上傳 |
| 🔔 顯示「登記失敗」 | 第 2 步的資料庫規則還沒發布；發布後重新整理網頁 |
| 執行記錄出現「資料庫讀取失敗（403）」 | 執行 Apps Script 的帳號不是 Firebase 專案擁有者；請改用擁有者帳號，或用下面的「備用做法」 |
| 推播失敗（403）提到 API 未啟用 | Google Cloud 主控台 → 專案 nanzi-sportsday →「API 和服務」→ 啟用「Firebase Cloud Messaging API」 |
| 測試推播成功、但正式通知沒跳 | 確認 Apps Script 左側「觸發條件」有「檢查並推播／每分鐘」；網站通知要由總控、司儀或紀錄組發送 |
| iPhone 沒跳 | 要從主畫面圖示打開過網站、iOS 16.4 以上、設定 → 通知 裡允許「運動會通報」 |

### 備用做法：服務帳號（學校帳號授權失敗時才用）
1. Firebase 主控台 → 專案設定 →「**服務帳戶**」→「產生新的私密金鑰」→ 下載 JSON 檔。
2. Apps Script 左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」：
   名稱 `SERVICE_ACCOUNT`，值貼上整個 JSON 檔的內容 → 儲存。
3. 再執行一次「測試推播」。
> 這個金鑰等於資料庫的萬能鑰匙，**只放在指令碼屬性，不要放進網站或 GitHub**。學校若有限制不能下載金鑰，就用預設做法。

## 費用與額度
全部免費。
- Apps Script 每分鐘檢查一次，一天約 1,440 次；沒有新通知時只讀一次資料庫。
- Email：學校帳號每天約可寄給 1,500 位收件人（同一封寄給 80 位老師算 80）。運動會當天發 15 則通知、每則 80 位，約 1,200，夠用。真的不夠時，執行記錄會寫「寄信額度不夠」。
- 不想寄 Email：把程式最上面的 `EMAIL_ON = true` 改成 `false`。
